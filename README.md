### Hi, I'm Jason Dalton 👋

**Founder @ [Cohestra](https://cohestra.org) | AI Systems Architect & Full-Stack Developer**

I build multi-agent orchestration planes, local AI automation networks, and practical developer tools. My work focuses on bridging cloud models with containerized local inference (`Ollama`, `Llama`), Model Context Protocol (MCP) integrations, and persistent knowledge architectures.

- 🔭 **Currently building:** **Cohestra** (multi-agent AI control plane) & **Lexicon** (personal AI automation network)
- 🧠 **Core Stack:** Python, TypeScript/JavaScript, C++, SQL, Bash
- ⚙️ **Infrastructure & Data:** Docker, Linux (Ubuntu/Fedora/WSL2), PostgreSQL, Qdrant, Redis, Tailscale
- 🌱 **Exploring:** Mixture-of-Agents (MoA) workflows, stateless MCP servers, and vector working memory schemas
